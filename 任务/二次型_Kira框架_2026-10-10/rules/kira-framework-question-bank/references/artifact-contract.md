# 分支题库的交付与验收

开始归集或制作时读取。以下约束信息完整性，不要求重建用户已有工程或采用固定技术框架。

## 最少记录

结构化清单优先用 JSON/CSV 或既有工程字段；不靠文件名、排版位置或题目文本拼接管理身份。字段名可适配现有格式，但这些关系不能丢。

| 记录 | 必需信息 |
| --- | --- |
| 本次范围 | 学科、考种、指定章/支、来源版本、明确排除项、目标产物 |
| 原框架节点 | 稳定节点 ID、原名、原顺序、原父节点、原件框架及 part 的定位、考种/待核状态 |
| 原件 | 原文件 ID 或任务局部 ID、真实路径、完整 SHA-256、文件类型、版本依据、抽取/原页核读状态 |
| 题目 | 稳定题 ID、完整题干及所有小问、原题号、全部来源定位、主节点和跨支关联、真实解法归类依据 |
| 学习入口 | 方法原页定位、代表题 ID、同题完整 Kira 板书定位、可用的小河花板书定位、匹配状态和缺口 |
| 覆盖处置 | 已归位、同题并入、明确排除、待归类/待核之一，理由与所合并题 ID；多小问关联保留父题上下文 |

PDF 定位从 1 开始按文件页序；印刷页码另列。非 PDF 使用标题、段落、表格、图片或文本区段，不虚构 PDF 页码。输出链接应能到实际原件；移动设备或另一库根可同时保留相对路径和源哈希，不能靠当前 Mac 的绝对路径当作身份。

## 题库页面的形态

沿原框架次序展开，不按基础/强化/专项重新分大组。每个最小教学分支先显示方法出处、代表例题及同题板书入口，再显示本支其他完整原题。来源标签可以简短，但准确来源对照必须另存。

代表题本体只排一次。跨支题通过引用或小问关联挂载；用户读到一支时须能取得所需的完整共同条件。普通题不为每一道另写长篇 AI 方法论，也不重复复制老师的整份讲义。

题目与答案分开。若用户要求速对，编号一一对应，所有小问、参数分类、取值范围、必要特殊解与原题疑点保留。只要求一个特解时，任何真实代回成立的答案都可，不把所列一种形式当成唯一答案。

## 不确定与不匹配

板书匹配状态至少区分同题完整、同题但不完整、仅方法参考、未找到/条件冲突。不完整讲解不能换成一条笼统链接冒充可学习入口。相同题号、年份和文件名都不是匹配证明。

一个框架支若无现有题或无可靠板书，应保留空缺；同类问题出现多解时保留主框架归属及明确副关联。不明确归属的题进入待归类清单，该清单不是新增的 Kira 题型节点。

无法读清核心符号，先重新查看原页和必要相邻页；仍不清则记录来源与缺口。原题有条件不足、原解不相容、漏特殊解或配套板书换题时，把原文与自己的检验分开说明。只有确认是派生材料的转录错误才修订题本，原件不动，旧版本不丢。

## 覆盖与完成

- 所有已发现的候选题都有处置，且去重前来源记录数、独立父题数与小问口径分别报告，不拿页数或副本数量凑题数。
- 所选原框架节点均可追溯原件；有题的分支都有方法位置和代表例题。要求完整学习导航时，每道代表例题必须有真正同题的完整讲解，否则是尚未完成的必需项。
- 明确未读/未索引材料、没有可靠文字层、缺页、待归类、范围待核和缺板书项目，不能用“关键词无命中”证明不存在相关题。
- 当用户只授权先建框架、只做一支或先交部分时，验收该有限目标，不能把局部完成扩写成全章/全库完成。
- 数学转录与解法归位必须读完整原文并核必要公式；哈希通过、OCR 取得、题目已收录、数学已验证、PDF 全页版式通过与实际掌握分别记录。

让最终产物回答四个问题：方法去哪学，示范看哪题，完整板书在哪，当前资料中这一支还有哪些题及未处理项。
