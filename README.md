## 校验

在本目录运行 `python3 scripts/verify_files.py`，检查清单内全部 PDF 的字节数及两种哈希，并检查是否多出未列入清单的 PDF。

发布验收另包含远程私有性检查、创建和修改测试文件的两次提交与推送，以及重新克隆后的完整文件校验。验收回执 `PUBLISH_RECEIPT.json` 在本地生成，不含凭据。
